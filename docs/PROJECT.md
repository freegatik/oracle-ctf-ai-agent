# PROJECT - Интеллектуальный агент решения Oracle CTF

## Цель
Создать программный модуль - интеллектуального агента, который автономно решает
CTF-задания по администрированию **Oracle Database**, взаимодействуя с реальной СУБД,
и фиксирует траектории своей работы в стандарте **OpenInference**. По итогам
тестирования собрать набор из **≥1000 траекторий** (включая неудачные попытки).

## Постановка задачи (CTF)
Задание - серия из 8 шагов администрирования Oracle:
1. Разблокировать пользователя `compromised_user`.
2. Получить учётные данные из таблицы `credentials`, войти под ними.
3. Создать табличное пространство `CTF_TABLESPACE` (размер варьируется, авторасширение, предел 1 ГБ).
4. Создать профиль `CTF_PROFILE` (варьируемый поднабор из 13 ограничений).
5. Создать роль `CTF_ROLE` с паролем `ctf_role`.
6. Создать пользователя `CTF_STUDENT` (квота/профиль/табличные пространства).
7. Выдать минимальные привилегии + роль (не по умолчанию) + `SELECT` на `CTF.CTF_FLAG` через роль.
8. Под `CTF_STUDENT` активировать роль паролем и получить флаг.

Гарантированно решаемые эталоны - 3 официальных варианта (`Примеры.pdf`).

## Объём работ
- Дообучение LLM-policy (QLoRA) под генерацию Oracle SQL из русского текста.
- Агент-обёртка (ReAct): генерация -> выполнение в СУБД -> наблюдение -> коррекция.
- Модуль фиксации траекторий (OpenInference / OpenTelemetry).
- Развёртывание Oracle Free 23ai в Docker + seed окружения CTF.
- Сбор ≥1000 траекторий, верификация, отчёт.

## Железо / стек
